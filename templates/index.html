Foundational Machine Learning Concepts in Classification

A structured guide explaining the core building blocks implemented in this Iris project

1

Supervised Classification

A branch of machine learning where the model learns mapping from input features $X$ to categorical targets $y$ using labeled training examples. The goal is to predict discrete classes (Setosa, Versicolor, Virginica).

2

Features vs. Labels

Features ($X$): The 4 input measurements (Sepal Length, Sepal Width, Petal Length, Petal Width).
Labels ($y$): The ground truth species identity to be predicted.

3

Train/Test Split & Stratification

We partitioned the 150 flowers into 80% Training (120) and 20% Testing (30). Using stratify=y ensures equal representation (10 flowers per species) in the test set to avoid sample bias.

4

Feature Standardization (StandardScaler)

Subtracts the mean and divides by standard deviation: $z = \frac{x - \mu}{\sigma}$. This prevents features with larger numerical magnitudes from dominating distance-based algorithms like SVM and KNN.

5

Evaluation Metrics Explained

Accuracy: Correct predictions / Total.
Precision: Correct species / All predicted as that species.
Recall: Correct species / All actual flowers of that species.
F1-Score: Harmonic mean of Precision and Recall.

6

Overfitting vs Generalization

A model that memorizes training noise will fail on new flowers. Evaluating strictly on unseen test data proves the model generalizes robustly (achieving 96.67% accuracy in reality).
